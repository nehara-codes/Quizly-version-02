# 🎯 Quizzly

Quizzly is a browser-based quiz game built with HTML, CSS, and vanilla JavaScript.

It allows users to choose a category, difficulty level, and number of questions, then complete a timed quiz with instant feedback, explanations, scoring, and a final results review.

This project was built as a hands-on JavaScript learning project to practice DOM manipulation, events, arrays, objects, functions, application state, localStorage, timers, and browser APIs.

---

## ✨ Features

- 🎯 Multiple quiz categories
- 📊 Easy, Medium, and Hard difficulty levels
- 🔢 Choose 5, 10, or 20 questions
- 🔀 Randomized questions
- 🔀 Randomized answer choices
- ⏱️ 15-second timer for each question
- ✅ Correct/incorrect answer feedback
- 💡 Explanation for each question
- 📈 Live score tracking
- 🏆 Final score and percentage
- 📝 Review of answered questions
- 💾 Best score saved using localStorage
- 🔊 Interactive sound effects using the Web Audio API
- 🔄 Play Again functionality
- 📱 Responsive interface

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- DOM Manipulation
- Web Audio API
- localStorage

No external frameworks or libraries are required.

---

## 🎮 How to Play

1. Open Quizzly in your browser.
2. Click **Start Quiz**.
3. Select:
   - Category
   - Difficulty
   - Number of questions
4. Click **Begin Quiz**.
5. Answer each question before the timer runs out.
6. Receive instant feedback and an explanation.
7. Complete the quiz to see your final score.
8. Review your answers or play again.
